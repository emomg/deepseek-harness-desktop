# dsh-desktop i18n 规范

## 必备文档三件套

每个对外可见的 npm 包必须有：

- `README.md`（英文）
- `README.zh.md`（中文）
- `README.i18n.yaml`（结构化配对）

`scripts/docs-check.mjs` 校验三件套齐全 + `i18n.yaml` 内的 entry id 存在。

## 命名空间约定

i18n key 用 `section.subsection.detail` 的形式：

- `settings.skins`  设置页 tab 名
- `skins.hint`      皮肤中心提示语
- `personalize.bg`  保留兼容老 pro 插件
- `errors.network`  错误码

i18n key 一旦发布就不能改——只能 deprecate + 新 key。

## 字符串纪律

- 不要硬编码任何用户可见字符串在 JSX / template 里
- 用 `t('key')` 调用
- 命名空间 `<package-name>`，在 host register 时指定

## CI 门禁

`pnpm docs:check` 跑通即认为双语配对 OK。改 README 任一侧必须同步另一侧
+ i18n.yaml，否则 CI 红。

## 新增 / 改 key 流程

1. 在 `lib/client.js` 的 `zh` / `en` 字典里加新 key
2. 同步更新 `README.i18n.yaml`（在 `entries:` 下加新行）
3. 更新对应 `README.md` / `README.zh.md` 里如果有引用
4. 跑 `pnpm docs:check`
5. commit

## 缩写

- `zh-CN` / `en` 两种 locale
- 字符串无 markdown / emoji / RTL 标记
- 占位符用 `{name}` / `{count}` 形式，不混用 `%s`
